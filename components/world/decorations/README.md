# World decorations

Put reusable room props and decorative 3D elements in `<decoration_name>/` packages here. Keep each decoration's scene, behavior, local resources, documentation and maintained demos together.

Keep biome-exclusive decorations under their owning biome's `shared/` folder. Shared production artwork belongs in `assets/`; lighting fixtures belong in `components/world/lighting/`, and structural pieces belong in `components/world/architecture/`.
