# Enemy expansion

36 additional enemies for floors 2–19. Each floor has two alternatives alongside its original opponent. The first enemy and final boss remain fixed. Runs remain 20 floors.

Profiles and starting stats are loaded from each `enemy.json`. Artwork is original layered Pixloom pixel art; native `.pixloom` projects and exact palette-index `.pixloom.json` sources accompany PNG/SVG exports. Art is installed at user request and awaits artistic acceptance. No separate sprite-frame animation is claimed; shared runtime animation applies.
