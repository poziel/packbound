# Game icons

Organize by purpose. Keep editable sources, exports and provenance with their icon package. Preserve artwork and symbol mappings during folder changes.

| Folder | Purpose |
| --- | --- |
| `navigation/` | Panel destinations, rewards and navigation actions. `panels/` and `actions/` retain the currently consumed families; `alerts/` holds the reward alert. Unused former navigation SVGs are archived. |
| `keywords/` | Inline stat/status/effect symbols. Each identity has its own folder; `registry.json` remains the runtime identity, color and texture mapping. |
| `actions/` | Action glyphs such as attack and enter dungeon. |
| `controls/` | Common previous/next/close, combat playback and settings controls. |
| `inventory/` | Adjacency feedback and stash reload glyphs. |

Superseded icon revisions were preserved in the verified ZIP at `workspace/archives/icons/asset-organization-2026-10-20.zip`. They are not active alternatives to add back into runtime folders. Navigation includes multiple current families because different controls still consume them; a visual redesign is separate work.
