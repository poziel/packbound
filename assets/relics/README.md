# Relics

Each relic owns a folder named with underscores, containing `README.md`, its
`relic.tres` gameplay definition and supporting resources, and its existing
structured identity/design records. `art/` contains PNG exports, editable sources,
art metadata and provenance where available.

The former `icons/art/` folders are now `art/`; art revisions remain inside it.
SVGs were removed and runtime texture references use matching PNGs. Stable relic
IDs and mechanics are unchanged. Shield Relic (`tower_shield`) remains a backpack
item under `assets/items/`.
