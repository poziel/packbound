# Sound effects

Group clips by playback responsibility:

- `combat/`: hits, damage, defenses and deaths; add attack/status subfolders when needed.
- `ui/`: activation, hover, inventory and other interface feedback.
- `transitions/`: loading, cover/reveal and other flow transitions.
- `candidates/`: supplied audition clips awaiting selection and an assigned event; not a runtime playlist.

Add event groups such as `world/` for doors, footsteps and room interactions when clips exist. Do not create empty speculative trees. Name accepted clips by event, keep provenance and preserve import settings. Music and continuous ambience belong in the sibling audio folders rather than SFX.
